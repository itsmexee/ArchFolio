# ArchFolio — Open-Source Architecture Portfolio Template

**ArchFolio** is a fast, minimalist, open-source portfolio template built for architects, interior designers, and 3D visualization artists. Created by **[Zarch Studios](https://www.zarchstudios.com)**.

Live Showcase: **[@designwithzeeshan](https://instagram.com/designwithzeeshan)**

---

### Key Features
- **Zero-Backend Architecture:** Pure HTML, Tailwind CSS, and Vanilla JS. Hosts 100% free on **Vercel**, **GitHub Pages**, or **Cloudflare Pages**.
- **Single-File Customization:** Update your bio, project renders, software stack, and social links inside `config.js` without touching HTML.
- **Built for High-Res Renders:** Lazy-loaded `.webp` support with a full-screen keyboard-accessible lightbox (`ESC` to close).
- **Optional Non-Intrusive AdSense:** Tasteful editorial sponsor slot disabled by default (`enabled: false`) so personal client portfolios remain clean.

---

### Quick Setup (3 Minutes)
1. Click **"Use this template"** or **Fork** this repository on GitHub.
2. Create an `assets/webp/` folder and upload your compressed `.webp` renders.
3. Open `config.js` and update your profile details, emails, and `projects` array.
4. Import your GitHub repository into **[Vercel](https://vercel.com)** and click **Deploy**.
